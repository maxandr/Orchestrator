# Unity Orchestrator

Локальный сервер с веб-страницей. Он делает игру на Unity **по частям** (фичам) командой агентов Claude Code:

- **Opus (архитектор):** изучает проект, проектирует фичу, режет её на задачи, ревьюит каждую задачу, ведёт «карту проекта».
- **Sonnet (исполнители):** `coder` (C#), `scene` (сцены/префабы), `ui` (интерфейс).
- **QA:** компиляция и EditMode-тесты через Unity CLI.

Агенты — это процессы вашего `claude` (Claude Code CLI). Они работают **по вашей подписке**, API-ключ не нужен.

## Запуск

```
npm install
npm run dev        # сервер :4321 + страница http://localhost:5173
```
или одним сервером: `npm run build && npm start` → http://localhost:4321

## Как работает фича

1. Добавьте Unity-проект (путь к папке с `Assets`). В проекте нужен git хотя бы с одним коммитом.
2. «Новая часть игры»: название и описание.
3. Opus присылает план: цель, критерии, задачи. Вы **утверждаете**, правите вручную или просите переделать.
4. Задачи идут по очереди: Sonnet делает → Unity проверяет компиляцию/тесты → Opus ревьюит diff. Если что-то не так, задача уходит на доработку (до 3 кругов). Принятая задача — отдельный git-коммит `[orchestrator] …`.
5. Если задача не прошла за 3 круга, она ждёт вас: «Ещё раз» с подсказкой, «Принять как есть» или «Пропустить и откатить».
6. В конце Opus пишет итог и обновляет карту проекта для следующих фич.

«Стоп» в любой момент останавливает агента. «Продолжить» возобновляет с текущей задачи, в том числе после перезапуска сервера или исчерпания лимита подписки.

## Проверка компиляции

- **Редактор открыт и в проекте стоит пакет Pipeline** (`unity pipeline install`): `unity recompile` прямо в редакторе.
- **Редактор закрыт:** Unity запускается в batch-режиме (`unity run … -quit`). EditMode-тесты (`unity test`) — тоже только при закрытом редакторе.
- **Редактор открыт без Pipeline:** проверка пропускается, ревью Opus всё равно идёт.

## Настройки (переменные окружения)

| Переменная | По умолчанию |
|---|---|
| `PORT` | `4321` |
| `ARCHITECT_MODEL` | `opus` |
| `EXECUTOR_MODEL` | `sonnet` |
| `CLAUDE_BIN` / `UNITY_BIN` | `claude` / `unity` |
| `ORCH_DATA_DIR` | `./data` (SQLite: проекты, фичи, задачи, лог) |

Промпты ролей лежат в `server/prompts/*.md`, их можно править под свой стиль.

## Структура

```
server/src/
  index.ts           HTTP API + WebSocket
  orchestrator.ts    цикл фичи: план → задачи → QA → ревью → итог
  agents/runAgent.ts запуск `claude -p --output-format stream-json`, стрим в лог
  agents/roles.ts    архитектор, исполнитель, ревьюер, итог (JSON-схемы)
  unity.ts           компиляция и тесты через Unity CLI
  git.ts             diff, коммиты, откат
server/prompts/      системные промпты ролей
web/src/             React-страницы: проекты, проект, фича (план, задачи, живой лог)
```
